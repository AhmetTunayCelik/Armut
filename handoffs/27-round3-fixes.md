# 27 Fixes after panel round 3, 2026-11-08
1. One first priority: D1 (event entry where new users look). Order: week 0 data pull and fake-door pre-test; weeks 1-4 D1; P1 starts only after D1's first read (week 3) or if D1's pre-test fails. Campaign copy test and listing filter: backlog, next quarter, because they touch paid-traffic pages and shared ranking that need the head of product.
2. P1 metric: second event request within 14 days per submitter (the card appears after submit, so it cannot change that session's submit). Guardrails: cancellations and 0-quote share on card requests vs organic.
3. Geo-targeting: show the D1 tile and block only to visitors whose city (detected or chosen on the site) is in a supply-gated cell (İstanbul, Ankara, İzmir first); others see today's homepage. Exposure numbers then cover those cities only (Istanbul alone ~40% of requests, Para Dergi 2026-10-07).
4. Competing explanation: event buyers may prefer Instagram, venues or düğün.com, so visibility would not help. Cheap pre-test before building: (a) 1-week fake-door tile (tile opens the existing search overlay, so it is real, not fake; cost ~2 days FE); (b) share of search sessions that type an event word (search logs); (c) 5 short interviews with recent event customers: where did you look first? If tile CTR is below the core-tile average and event search share is tiny, rethink D1 before investing.
5. Copy without unchecked promises: A "Armut'ta düğün fotoğrafçısı da var: ücretsiz teklifler al"; B "İstanbul'da [N] düğün fotoğrafçısı" shown only when N >= 50, else "Düğün fotoğrafçılarından ücretsiz teklif al"; C "Düğününe az kaldıysa: bugün teklif al" only in cells where 48h quote rate passes the gate.
6. Local listing sketch: an "Son 12 ayda aktif" badge and default filter for event categories; profiles inactive 24+ months move to the end, not removed. Guardrails: quotes per request, time to first quote. Needs head of product (ranking).
7. Instrumentation: separate events for tile tap, block impression, block tap, request start (source), submit (source). MDE behind the 4-week runtime: +20% relative on an assumed 0.3% event-submit baseline.
