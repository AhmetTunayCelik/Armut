# 18 Simulations of possible outcomes (v5), 2026-11-07
Script: simulation/sim.py (numpy, 100,000 Monte Carlo runs, seed 42). Tables generated by simulation/report.py from simulation/results.json, so numbers match the model exactly.
Real inputs: yearly customers per service (handoff 15); measured 0/315 event mentions in cleaning/moving/furniture and 27/73 in masa sandalye. Assumed: every rate, as triangular ranges in sim.py. Scenarios, NOT forecasts. Armut funnel data would replace every range.

## v5 change
- Added D1, a discovery entry for new users (event services in homepage lists and the search empty state). Search itself maps event words well (tested live), so the gap is that nothing tells users Armut does events. Seasonal slot (C2) is folded into D1 as its seasonal rotation.

## v4 change
- Added hidden event demand found in boat and venue services: yat kiralama 8,792/yr (52% of Istanbul samples are events), tekne kiralama 7,737/yr (33%), düğün salonu 4,114/yr. Event base now ~108,000. Hosting bridge now includes yat/tekne.

## v3 change
- Card CTR priors now split by entry type, anchored on measured second-need mentions in real request text (handoff 19): cake buyers 0.5-4% (focused), birthday organization / palyaço 2-9%, nişan organization 2-9%, other wedding-chain 1-5%. Program total tightened.

## Changes after the independent review (v2)
- Card CTR lowered (post-request cards usually 1-5%): A1 mode 4% (was 7%), A2 3.5%. Card submit raised to 52% (user just signed up).
- Hosting event share raised to mode 40% (measured 37%; catering likely higher).
- Price/local pages: year-1 SEO ramp (40-80%) and page cannibalization (70-100%) added.
- Seasonal slot: scaled to the season share of the year (25-50%).
- WhatsApp concierge: base changed to non-submitting visitors, incrementality 30-60% added; result is capped by ops capacity, so effort now includes ops hours.
- Birthday comeback: reachable share lowered for İYS consent (15-40%); test reach now the reachable cohort, so it reads in ~18 weeks, not 2.
- Copy angle test and press report have made-up ranges: treated as learning tests, not volume bets.
- Program totals sum joint draws; overlaps still exist (A1 and C1 share birthday customers; card drop-offs feed B2), so the combined total is an upper-leaning estimate.
